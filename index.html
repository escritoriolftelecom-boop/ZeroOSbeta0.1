A ideia

Leve no sistema.
Grande na liberdade.

O ZeroOS nasce para transformar um pendrive em uma forma prática de levar um ambiente Linux com você. O projeto está em desenvolvimento e evolui a cada compilação e teste.

Por dentro do ZeroOS

O essencial, sem excesso.

Uma seleção de componentes conhecidos do ecossistema Linux, priorizando simplicidade e baixo consumo.

◈

Base Debian Live

Estrutura baseada no Debian Live para inicialização a partir de mídia USB.

▦

Desktop Openbox

Gerenciador de janelas enxuto, com Tint2 para uma área de trabalho prática.

⌁

Ferramentas úteis

Planejado com navegador Falkon, PCManFM, terminal e NetworkManager.

Acompanhe o desenvolvimento

O ZeroOS está em construção.

A imagem ISO já teve uma compilação inicial, mas ainda precisa ser testada em máquinas reais antes de ser considerada pronta para uso.

Não use como sistema principal nem em equipamentos com dados importantes. Consulte o repositório para ver o estado atual e os artefatos de compilação.
