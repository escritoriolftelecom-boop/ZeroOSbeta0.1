# ZeroOS

Sistema operacional portátil baseado em Debian Live, com ambiente leve Openbox e foco em inicialização por USB.

## Estado

Estrutura inicial do projeto. A ISO ainda precisa ser compilada e testada.

## Componentes planejados

- Debian Live
- Openbox e Tint2
- NetworkManager
- PCManFM e LXTerminal
- Falkon como navegador

## Compilar

O workflow em `.github/workflows/build.yml` prepara uma compilação automática usando GitHub Actions.
